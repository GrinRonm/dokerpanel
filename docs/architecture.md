# Архитектура DockerPanel

DockerPanel спроектирована как легковесное, высокопроизводительное монолитное приложение без излишних зависимостей.

## Ключевые компоненты

### 1. Веб-сервер (Nginx)
Nginx выступает в роли обратного прокси-сервера. Он:
- Напрямую и очень быстро отдаёт статические файлы (CSS, JS, картинки).
- Перенаправляет все PHP-запросы (через `index.php`) к PHP-FPM.
- Перехватывает обращения к `/ws/` и проксирует их к фоновому Python WebSocket-серверу для работы терминала.

### 2. Backend (PHP 8.x + Custom MVC)
Мы отказались от тяжелых фреймворков вроде Laravel или Symfony в пользу собственного минималистичного MVC-ядра.
- **Точка входа:** `index.php` перехватывает запросы и проверяет роутинг.
- **Роутер:** Файл `config/routes.php` сопоставляет URL-адреса с контроллерами.
- **Взаимодействие с Docker:** Мы не используем сторонние SDK. `DockerService.php` отправляет прямые HTTP-запросы через UNIX-сокет `/var/run/docker.sock` в Docker Engine API (v1.44+). Это обеспечивает молниеносную скорость и минимальное потребление ОЗУ.

### 3. Фоновый WebSocket-сервер (Python)
PHP плохо подходит для асинхронных долгоживущих подключений. Поэтому для работы интерактивного терминала (xterm.js) используется демон на Python:
- Слушает порт `8765`.
- Принимает апгрейд до WebSocket.
- Создает псевдотерминал (PTY) с помощью библиотеки `pty` (или напрямую делает `docker exec -it ...`).
- Передаёт стандартный ввод/вывод (stdin/stdout) между браузером и контейнером в реальном времени.

### 4. База Данных (SQLite 3)
Для хранения метаданных контейнеров, пользователей, шаблонов и настроек используется SQLite. Файл БД хранится в `storage/database/database.sqlite`. Выбор SQLite обусловлен тем, что панель предназначена для управления одним узлом (сервером), и использование MySQL/PostgreSQL было бы неоправданной тратой ресурсов сервера.

### 5. Frontend (Vanilla JS)
- Никакого React/Vue. Используется чистый Vanilla JavaScript.
- Обновление интерфейса (например, графики мониторинга) работает через `fetch` и микро-компоненты.
- Страницы загружаются через AJAX для имитации SPA (Single Page Application), что исключает мигание экрана при переходе между разделами.
- **Терминал:** Интегрирована библиотека `xterm.js` для отрисовки терминала.
- **Редактор кода:** `CodeMirror 5` для редактирования файлов внутри контейнеров.
