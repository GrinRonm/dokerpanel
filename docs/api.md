# Документация REST API DockerPanel

Панель предоставляет закрытое REST API для программного управления контейнерами.
Для доступа к API требуется передавать HTTP-заголовок `Authorization: Bearer <API_TOKEN>` во всех запросах.
Токен можно сгенерировать в разделе профиля администратора.

## Формат ответов

Все ответы API возвращаются в формате JSON:

```json
{
  "success": true,
  "message": "Контейнер запущен",
  "data": { ... }
}
```

## Эндпоинты

### Контейнеры

#### 1. Получить список контейнеров
- **Метод:** `GET`
- **URL:** `/api/v1/containers`
- **Описание:** Возвращает список всех созданных контейнеров и их текущий статус.

#### 2. Создать контейнер
- **Метод:** `POST`
- **URL:** `/api/v1/containers/create`
- **Тело (JSON):**
  ```json
  {
    "name": "my_ubuntu",
    "image": "ubuntu:latest",
    "ports": {"8080": "80"}
  }
  ```

#### 3. Управление контейнером (Start/Stop/Restart/Delete)
- **Метод:** `POST`
- **URL:** `/api/v1/containers/action`
- **Тело (JSON):**
  ```json
  {
    "id": "container_docker_id",
    "action": "start" // или "stop", "restart", "delete"
  }
  ```

### Системная информация

#### 4. Статистика сервера
- **Метод:** `GET`
- **URL:** `/api/v1/system`
- **Описание:** Возвращает текущее использование CPU, RAM, диска и количество активных контейнеров на хост-сервере.
