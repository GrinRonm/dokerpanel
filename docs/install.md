# Руководство по установке DockerPanel

## Системные требования

Минимальные требования к серверу для комфортной работы панели:
- **ОС:** Ubuntu 20.04+, Debian 11+
- **CPU:** 1 ядро
- **RAM:** 1 ГБ (рекомендуется 2 ГБ для комфортной работы контейнеров)
- **Диск:** 10 ГБ SSD
- **Порты:** 80 (HTTP), 443 (HTTPS), 22 (SSH)

## Установка в 1 клик (Рекомендуется)

Мы подготовили bash-скрипт, который автоматически установит все необходимые зависимости и настроит панель.

Подключитесь к вашему серверу по SSH под пользователем `root` (или с правами `sudo`) и выполните команду:

```bash
curl -sSL https://raw.githubusercontent.com/GrinRonm/dokerpanel/main/scripts/install.sh | sudo bash
```

### Что делает установщик:
1. Устанавливает пакеты: `nginx`, `php-fpm`, `php-sqlite3`, `php-curl`, `python3`, `docker.io`
2. Клонирует репозиторий в `/var/www/dockerpanel`
3. Назначает правильные права доступа для пользователя `www-data`
4. Настраивает Nginx для проксирования веб-интерфейса и WebSocket
5. Создает базу данных SQLite с таблицами и базовыми шаблонами
6. Настраивает фоновый WebSocket-демон в `systemd`

## Первоначальная настройка

Сразу после установки откройте в браузере IP-адрес вашего сервера (например, `http://192.168.0.10`).

- **Логин:** `admin`
- **Пароль:** `admin`

> **Важно!** При первом входе обязательно перейдите в **Настройки** -> **Профиль** и смените пароль администратора на более надежный!

## Обновление системы

DockerPanel поддерживает автообновление "по воздуху".
Перейдите в веб-интерфейсе в раздел **Настройки** -> **Обновление** и нажмите "Проверить обновления". Если обновление доступно, нажмите "Обновить сейчас".

## Решение проблем (Troubleshooting)

- **Панель не открывается (Ошибка 502/500):** Проверьте логи Nginx и PHP-FPM: `tail -n 50 /var/log/nginx/error.log`.
- **Терминал не подключается:** Убедитесь, что порт 8765 не блокируется фаерволом, и демон работает: `sudo systemctl status dockerpanel-terminal`.
- **Нет связи с Docker:** Проверьте, добавлен ли пользователь `www-data` в группу `docker` и доступен ли сокет `/var/run/docker.sock`.
