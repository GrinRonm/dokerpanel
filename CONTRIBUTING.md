# Contributing to DockerPanel

Спасибо за интерес к развитию DockerPanel! Мы приветствуем любые пулл-реквесты (Pull Requests), баг-репорты (Issues) и предложения новых функций.

## Как сообщить о баге
1. Убедитесь, что вы используете самую последнюю версию панели.
2. Проверьте вкладку [Issues](https://github.com/GrinRonm/dokerpanel/issues), возможно, об этой ошибке уже сообщили.
3. Опишите баг максимально подробно: шаги для воспроизведения, логи Nginx/PHP, ожидаемое поведение.

## Как предложить код (Pull Request)

1. Сделайте **Fork** этого репозитория.
2. Создайте новую ветку (`git checkout -b feature/amazing-feature`).
3. Внесите изменения в код. Постарайтесь придерживаться текущего стиля программирования (Vanilla JS, процедурный/классовый PHP 8.x без сторонних ORM и фреймворков).
4. Убедитесь, что ваш код не ломает существующий функционал.
5. Закоммитьте изменения (`git commit -m 'Add some amazing feature'`).
6. Запушьте ветку (`git push origin feature/amazing-feature`).
7. Откройте **Pull Request** в ветку `main`.

## Стиль кода
- **PHP:** Придерживаемся стандарта PSR-12. Строгая типизация, где это возможно.
- **JavaScript:** ES6+. Использование `async/await` вместо коллбэков. Никаких сторонних UI-библиотек (jQuery, React и т.д.) — только чистый JS.
- **HTML/CSS:** Семантическая верстка. CSS переменные для цветов (чтобы поддерживать тёмную/светлую тему).

Будем рады вашей помощи!
