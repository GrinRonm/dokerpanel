# Changelog

Все заметные изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-07-30
### Added
- Автоматическая система проверки обновлений с GitHub (One-click update).
- `docs/` директория с документацией по API, архитектуре и установке.
- Интегрирован красивый логотип DockerPanel в сайдбар.

### Changed
- Web-терминал теперь открывается в модальном окне поверх текущей страницы (вместо новой вкладки).
- Терминал сохраняет историю команд и вывод при закрытии/открытии модального окна для одного и того же контейнера.
- Улучшена обработка отключений WebSocket.

### Fixed
- Исправлен баг, из-за которого панель неправильно проверяла обновления через Releases API.
- Исправлена ошибка `App is not defined` при рендеринге терминала.

## [1.0.0] - 2026-07-29
### Added
- Инициализация проекта.
- Встроенный редактор кода CodeMirror для просмотра/редактирования файлов контейнера.
- CRUD операции с контейнерами.
- Интерактивный терминал (xterm.js + Python WebSockets).
- Dashboard с красивым дизайном и графиками потребления ресурсов.
- Базовая система авторизации.
