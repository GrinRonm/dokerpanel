# DockerPanel

DockerPanel — это современная, легкая и быстрая веб-панель для управления Docker контейнерами, образами, сетями и томами.

## Особенности
- 🚀 **Установка в один клик**
- 📊 **Мониторинг в реальном времени** (CPU, RAM, Диск, Сеть)
- 🖥️ **Встроенный веб-терминал** для работы с контейнерами
- 📁 **Файловый менеджер** с умным редактором кода (подсветка синтаксиса JS, PHP, HTML и др.)
- 🔄 **Автообновления** прямо из панели управления
- 📅 **Резервное копирование по расписанию** (Cron)
- 🔒 Легкая база данных SQLite (не требует MySQL)
- ⚡ Написано на Vanilla JS и PHP 8 (работает моментально)

## Установка (Ubuntu / Debian)

Выполните эту команду на чистом сервере под пользователем `root` (или с правами `sudo`):

```bash
curl -sSL https://raw.githubusercontent.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/dockerpanel/main/install.sh | bash
```

*Скрипт автоматически установит Nginx, PHP, Docker (если нет) и саму панель управления.*

### Вход по умолчанию
- **URL**: `http://IP_ВАШЕГО_СЕРВЕРА`
- **Логин**: `admin`
- **Пароль**: `admin`

*(Не забудьте сменить пароль после первого входа!)*

## Системные требования
- ОС: Ubuntu 20.04/22.04/24.04 или Debian 11/12
- RAM: от 512 MB
- Web-сервер: Nginx (устанавливается автоматически)
- PHP: 8.x (устанавливается автоматически)
