## 📌 О проекте

DockerPanel — это open-source решение, созданное для того, чтобы максимально упростить работу с Docker. Забудьте о длинных консольных командах: теперь управлять контейнерами, образами, сетями и томами можно через интуитивно понятный графический веб-интерфейс, который работает молниеносно.

### 🌟 Ключевые возможности

- 🚀 **Установка в один клик** (весь стек разворачивается автоматически)
- 📊 **Мониторинг ресурсов в реальном времени** (CPU, RAM, Диск, Сеть)
- 🖥️ **Встроенный веб-терминал** (мгновенное подключение к консоли любого контейнера через WebSocket + xterm.js)
- 📁 **Мощный файловый менеджер** с умным редактором кода (CodeMirror с подсветкой синтаксиса)
- 🔄 **Автообновления** (система сама проверяет наличие новых версий на GitHub)
- 📅 **Резервное копирование по расписанию** (интеграция с Cron)
- 🔒 **Легкая архитектура** (работает на SQLite + Nginx + PHP 8, не перегружает сервер)
- ⚡ **SPA-интерфейс** (написан на Vanilla JS, без тяжелых фреймворков)

## 🛠️ Архитектура и стек технологий

Проект построен по классическому MVC-паттерну (Model-View-Controller) и не использует тяжеловесных фреймворков, что делает его невероятно быстрым.

- **Backend:** PHP 8.x
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3, Bootstrap 5
- **Веб-сервер:** Nginx (работает как reverse-proxy для WebSocket)
- **База данных:** SQLite 3 (лежит в `storage/database/database.sqlite`)
- **Терминал:** Python 3 (сервер) + WebSockets + `xterm.js` (клиент)

### Структура директорий проекта

```text
dockerpanel/
├── app/                  # Ядро Backend'а (MVC)
│   ├── Controllers/      # Контроллеры (обработка HTTP-запросов)
│   ├── Helpers/          # Вспомогательные классы (Security, Validator, Response)
│   ├── Middleware/       # Middleware (Auth, CSRF защита)
│   └── Services/         # Сервисы бизнес-логики (Docker, Nginx, Monitor, Update)
├── config/               # Конфигурационные файлы (роутинг, БД, константы)
├── database/             # SQL-скрипты схемы и сидов БД
├── public/               # Публичная директория (Frontend)
│   ├── css/              # Таблицы стилей
│   ├── js/               # JavaScript модули (SPA-архитектура)
│   └── index.php         # Единая точка входа
├── scripts/              # Bash/PHP скрипты для автоматизации (cron, update)
├── storage/              # Локальное хранилище данных
│   ├── backups/          # Резервные копии базы данных
│   ├── database/         # SQLite база данных
│   └── logs/             # Логи системы и терминала
├── views/                # HTML/PHP шаблоны страниц
└── websocket/            # Сервер веб-терминала на Python
```

## 🚀 Установка (Ubuntu / Debian)

Выполните эту команду на чистом сервере под пользователем `root` (или с правами `sudo`):

```bash
curl -sSL https://raw.githubusercontent.com/GrinRonm/dokerpanel/main/install.sh | bash
```

*Скрипт автоматически установит Nginx, PHP, Docker (если его нет) и саму панель управления, а также настроит WebSocket-прокси.*

### 🔐 Вход по умолчанию
- **URL**: `http://IP_ВАШЕГО_СЕРВЕРА`
- **Логин**: `admin`
- **Пароль**: `admin`

*(Обязательно смените пароль после первого входа!)*

## ⚙️ Внутреннее устройство (Для разработчиков)

### 1. Роутинг и SPA
На клиенте реализована архитектура Single Page Application (SPA) в `public/js/app.js`. Все переходы между страницами происходят через AJAX без перезагрузки страницы. Роутинг на сервере описан в `config/routes.php` и обрабатывается единой точкой входа `index.php`.

### 2. Взаимодействие с Docker
Панель взаимодействует с Docker Engine напрямую через **Docker Engine API** (через сокет `/var/run/docker.sock`), используя `curl` в PHP (класс `DockerService.php`). Это позволяет избежать использования тяжелых внешних библиотек.

### 3. Веб-терминал
Терминал реализован как отдельный фоновый процесс (daemon) на Python (`websocket/terminal_server.py`). 
Он использует библиотеку `ptyprocess` для создания псевдотерминала (PTY) и подключается к контейнеру с помощью команды `docker exec -it`. Nginx настроен на проксирование WebSocket-трафика с маршрута `/ws/` на внутренний порт Python-сервера (8765).

### 4. Файловый менеджер
Редактор кода построен на базе `CodeMirror` и поддерживает загрузку/скачивание файлов, создание директорий и редактирование текстов с автоматическим определением синтаксиса файла (JS, PHP, YAML, JSON, Bash).

### 5. Безопасность
- **CSRF-токены:** Все POST-запросы проверяются на наличие валидного CSRF-токена.
- **SQLite PDO:** Все запросы к БД используют подготовленные выражения (Prepared Statements) для защиты от SQL-инъекций.
- **Аудит логов:** Действия пользователей логируются в базе данных для отслеживания изменений.
